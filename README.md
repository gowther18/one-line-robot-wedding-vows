One line, 65 characters: the funniest single line of wedding vows a robot couple could say. The joke is a lie baked into the vow itself — a robot promising to click "I am not a robot" for its beloved, every single time. The contradiction is the punchline, and it only works because the speaker is a machine.

> I promise to click 'I am not a robot' for you, every single time.

Run it: `python3 main.py` (writes /output/entry.txt).
